💻免费开源，本地跑大模型两件套
正文 
想在自己电脑上跑大模型，不花API钱、数据也不出门？这两个开源工具先收藏💻

🦙 Ollama
• 协议：MIT，可免费使用
• 定位：一条命令拉模型、跑模型，官方简介支持Qwen、Gemma、DeepSeek、gpt-oss等
• 适合：想最快上手的新手
• GitHub 约18.7万⭐（截至11月13日）

⚙️ llama.cpp
• 协议：MIT
• 定位：C/C++写的大模型推理引擎，很多本地工具的底层
• 适合：想折腾性能、深度定制的开发者
• GitHub 约13.5万⭐（截至11月13日）

💡 小贴士
• 模型本身有各自的许可证，商用前去模型页看清楚
• 电脑配置决定能跑多大的模型，先从小参数的试起

⚠️ 只从官方GitHub仓库下载，别信网盘“破解整合包”。

这周GitHub热榜被AI Agent工具刷屏了，挑3个可商用协议的给你🔥

• 一个爬虫框架，从单次请求到整站爬取都能管
• BSD-3-Clause，Python

• 给AI Agent用的浏览器自动化命令行工具

• 给AI Agent用的电脑操作命令行工具（computer use CLI）
